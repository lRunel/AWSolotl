Arecanut Disease Detector

99.95% accuracy — validated on a test set with a completely different viewpoint distribution than training

accuracy

Arecanut is Karnataka's primary cash crop. Farmers lose significant yield to diseases that are invisible until advanced. This system detects them from a phone photo or a drone survey — on-device, offline, no server. The interesting engineering was not getting high accuracy — it was proving the accuracy was real.

Why the accuracy number actually means something

Most models trained on ground-level photos collapse when tested on drone footage — the viewpoint, scale, lighting, and angle are fundamentally different. This model was evaluated on a separate external dataset with a different distribution from training. Accuracy held at 99.95%.

To verify the distributions were actually different (not just relabeled copies), MobileNetV2 embeddings were extracted from both sets and compared using cosine similarity and t-SNE visualization. The feature spaces were genuinely different. That makes the result meaningful.

Technical Highlights

1. The RGBA→BGR problem

React Native gives RGBA from camera. The Python training pipeline used OpenCV which reads BGR. Feeding RGBA into a BGR-trained model gives wrong predictions even when the image looks identical. Fix: read raw pixels from a Skia surface and manually reorder channels before building the Float32Array. Small detail, real consequence — without this the model would be unusable on mobile.

2. Domain shift validation

Used MobileNetV2 + t-SNE + cosine similarity to confirm the external test set was genuinely out-of-distribution — not just a different split of the same photos.

3. INT8 quantization

Full Keras H5 → TFLite INT8. Model is ~3MB, runs entirely on-device, no internet required.

Limitations

  • Limited to 9 trained classes — novel diseases not recognized
  • Drone pipeline tested at one altitude range
  • Chatbot is keyword-matching only, not semantic
  • iOS build untested (Android primary)
  • Real-time video inference not implemented
