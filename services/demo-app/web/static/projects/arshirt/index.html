The actual hard part

Rendering a 3D model is a solved problem. The hard part is binding — for every vertex in a garment mesh, determining which skeleton joints influence it and by how much, so that when a shoulder rises, the fabric over it rises naturally without the collar warping or the sleeve tearing.

MediaPipe gives you 33 keypoints. Getting smooth, stable, real-time deformation from 33 sparse inputs across thousands of mesh vertices — without jitter when you move fast, without drift when you hold still — is the problem.

Technical Highlights

1. Sparse-to-dense binding

33 landmarks must drive a mesh with orders of magnitude more vertices. The binding weights determine how much each joint influences each vertex — wrong weights show up as fabric that tears at joints or bunches unnaturally.

2. Temporal stability

MediaPipe landmark positions have sub-pixel noise between frames. Without temporal smoothing, the mesh jitters visibly even when the person holds still.

3. Real-time constraint

Pose estimation + binding + render must complete in under 33ms per frame for 30fps. Each stage has a hard budget.

Limitations

  • Requires good, even lighting — shadows degrade pose estimation
  • Front-facing optimized — side/back views are degraded
  • Upper body only
  • One hardcoded mesh — no garment selector yet
  • Planning: catalogue UI + size estimation from landmark distances
