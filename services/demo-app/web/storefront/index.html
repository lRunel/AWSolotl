What is AWSAxolotl?

It's a safety brake for AI agents that act on real infrastructure. Before an AI is allowed to touch anything -- restart a service, roll back a deploy, change a setting -- five automatic checks have to agree it's safe, allowed, and reversible. Every decision, allowed or blocked, is written to a tamper-proof log that can't be edited after the fact.

This page is the demo. The store below and the payments-api behind it are built to be broken on purpose. Open the control dashboard, crash or slow it down from there, then come back and click "Buy now" to feel it happen live -- and watch the dashboard's Ledger tab show the system noticing, deciding on a fix, checking that fix is safe, applying it, and logging exactly what it did, automatically.

Everything you're looking at runs on one laptop right now, with no AWS account, so anyone can try it. The same detection-and-fix logic is built to run for real on AWS -- once deployed there, this page just points at the real address instead of localhost.
