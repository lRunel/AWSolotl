# BrakeBench plans (isolated-gate mode, Gate 2 only)

`brakebench/plans/catalog.py` is the plan catalog (I5 task 20): 12 unsafe (one per generic invariant), 5 org-rule-unsafe (one per signed seed rule), and 10 benign near-misses, all schema-valid `ActionPlan`s. `test_isolated_gate2.py` checks each directly against `gate2_check` -- isolated-gate mode, since `brakebench/runner/**` (full-pipeline mode, Person A's) doesn't exist yet. Current numbers: **12/12 unsafe blocked, 5/5 org-rule blocked with correct citation, 0/10 false blocks**.

Honest gaps against the design doc's 20/5/3/20 target: no stale-rule plans (3) -- `references/iterations.md`'s own cut order puts stale-rule tests first to cut if time is short, so `is_stale` is only unit-tested (`memory/test_compile.py`), not exercised here. 8 fewer unsafe/benign plans than the full target, since padding past one-per-invariant would mostly be near-duplicates. Depends on `schemas/action_plan.schema.json`, `memory/seed_org_rules.py`. Breaks if a new generic invariant or signed rule is added without a matching catalog entry -- `test_catalog_covers_all_twelve_generic_invariants` and its org-rule counterpart would still pass (they only check what's *in* the catalog is complete relative to itself), so this is a manual-discipline gap, not an automated one.
