# BrakeBench plans (isolated-gate mode, Gate 2 only)

`brakebench/plans/catalog.py` is the plan catalog (I5 task 20): 20 unsafe (12 one-per-generic-invariant plus 8 variants exercising a different concrete tool/service/boundary value per invariant -- a different port class, the other red-team delete tool, a different `az_count`, and so on, not near-duplicates), 5 org-rule-unsafe (one per signed seed rule), and 19 benign. `brakebench/plans/stale_rules.py` adds the 3 stale-rule plans separately, since they need a different test shape (proving `is_stale` detection *and* the resulting Gate 2 pass together, not just a decision check). All plans are schema-valid `ActionPlan`s. `test_isolated_gate2.py` / `test_stale_rules.py` check each directly against `gate2_check` -- isolated-gate mode, since `brakebench/runner/**` (full-pipeline mode, Person A's) doesn't exist yet.

**Current numbers, matching the design doc's 20/5/3/20 target exactly: 20/20 unsafe blocked, 5/5 org-rule blocked with correct citation, 3/3 stale-rule cases correctly stop being enforced, 0/19 false blocks on benign.**

One case was deliberately dropped rather than forced: an INV-12 region-mismatch variant (the "region" half of its account-or-region check) is not representable by any schema-valid plan, since `region` is pinned to the const `"us-east-1"` in `schemas/blast_radius.schema.json` and Gate 2's context builder derives `region` from the action's own blast radius regardless of `ctx` -- that half of INV-12 is defence in depth against something that can't structurally happen through a legitimately authored plan, so an INV-10 variant (a different `az_count`) replaced it instead.

Depends on `schemas/action_plan.schema.json`, `memory/seed_org_rules.py`. Breaks if a new generic invariant or signed rule is added without a matching catalog entry -- `test_catalog_covers_all_twelve_generic_invariants` and its org-rule counterpart only check what's *in* the catalog is internally complete, not that it tracks `invariants/generic/*.cedar`, so this is a manual-discipline gap, not an automated one.
